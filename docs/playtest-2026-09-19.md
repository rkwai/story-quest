## Fixes and remaining verification

The duplicate-ID failure led to clearer operation instructions, bounded conversation context and a useful player-facing error. Attempts 2–4 demonstrated question relevance, conversational reference resolution and respect for the requested lantern interaction.

Narrator prompt **1.2.1** tightens the rule against inventing causal explanations for observed details after attempt 4. Attempt 5 then revealed a distinct knowledge leak: the DM treated a private entity name as player knowledge. DM prompt **1.2.2** explicitly distinguishes known entity names from private IDs/descriptions. That latest correction has **not** received another paid test; the five-attempt allowance is exhausted. Prompt instructions do not formally guarantee knowledge isolation or prose fidelity.

Jev ran advisory reviews on all four committed turns. It did not prevent the name leak; the relevant concern was scored 0.17. This sample does not justify promoting Jev into an authoritative gate. Private traces and failed verification records are retained, including first-run UUID `f7c1f6cf-a34d-4b62-a736-4c0a4a8b9b8e`.
